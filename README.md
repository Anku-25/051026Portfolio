# Digital Marketer Portfolio Website

A high-converting, modern portfolio built specifically for digital marketers, growth specialists, and performance advertisers.

## 📁 File Structure

```text
051026Portfolio/
│
├── index.html              # Home Page (Introduction, Key Metrics, Services, Testimonials)
├── work.html               # Portfolio & Case Studies (Dynamic filter by SEO, PPC, Social, Email, CRO)
├── contact.html            # Contact Page (Inquiry form, contact info, calendar & social links)
│
├── css/
│   ├── style.css           # Core styling, color variables, typography, and layout
│   └── responsive.css      # Mobile and tablet responsiveness
│
├── js/
│   ├── main.js             # Mobile navigation menu & dynamic footer year
│   └── filter.js           # Interactive category filtering logic for projects
│
└── assets/
    └── images/
        └── projects/       # Add your campaign screenshots, graphs & banners here
```

## 🚀 How to Preview & Open
1. Double-click `index.html` in your file explorer to open it in your browser (Google Chrome, Edge, etc.).
2. You can switch between pages using the top navigation bar.
3. On `work.html`, click any filter button (**SEO**, **Google Ads / PPC**, **Paid Social**, etc.) to test the filtering animation.
